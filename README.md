# Пульс канала — полный комплект

В этом архиве две папки:

- `github-pages/` — готовые файлы для публикации на GitHub Pages. Загрузите **содержимое этой папки** в корень репозитория. Подробные шаги есть в `github-pages/README.md`.
- `source/` — исходный проект с манифестом Sites и папкой `dist/`.

Сайт полностью статический: для GitHub Pages не нужны Node.js, сборка или собственный сервер. Секретный ключ Google в архив не включён. Публичный OAuth Client ID находится в `app.js`.

Чтобы вход через Google работал на этом GitHub Pages, добавьте `https://sonicgames1807-star.github.io` в **Authorized JavaScript origins** OAuth-клиента. Пока приложение Google находится в режиме Testing, войти могут только добавленные тестовые аккаунты. На телефоне открывайте сайт прямо в Chrome или Safari, а не во встроенном браузере другого приложения.

## Что проверено

- Синтаксис JavaScript и состав обоих архивов.
- Загрузка страницы и независимые периоды показателей в браузере.
- Мобильная ширина 390 px без горизонтального переполнения.
- Запросы и расчёты на имитации ответов YouTube API: канал, видео, сравнение периодов, период «всё время», сценарий роста и сохранение цели.

Прогноз в «Лаборатории роста» — расчёт по прошлым 28 дням, а не гарантия будущего результата. Отчёты YouTube Analytics могут поступать с задержкой.
